# BUK Computer Science 2021 Reunion

Static site for the reunion: countdown, RSVP and payment evidence via WhatsApp, PalmPay details, confirmed attendees, contributors and classmates still to reach.

## Updating the lists

1. Open the site with `#organiser` at the end of the URL.
2. Add attendees, contributions or missing classmates, or change the event settings.
3. Tap **Copy data.json**, open `data.json` in this repo, replace its contents and commit.

The site reads `data.json` on every load, so changes appear once GitHub Pages redeploys (usually a minute or two).
